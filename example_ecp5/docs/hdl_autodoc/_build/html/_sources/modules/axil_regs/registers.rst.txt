axil_regs — Register Map
========================

   :header-rows: 1

   :class: register-table

   * - Register
     - Offset
     - Access
     - Description
   * - ctrl
     - 0x00
     - r/w
     - Control register for the stream filter.
   * - status
     - 0x04
     - r
     - Filter status.
   * - threshold
     - 0x08
     - r/w
     - Filter threshold.
   * - scratch
     - 0x0C
     - r/w
     - General-purpose scratch register. Reads back what was written; no effect on the design.

ctrl (0x00)
-----------

.. list-table::
   :header-rows: 1
   :widths: 15 20 20 45
   :class: register-table

   * - Field
     - Type
     - Default
     - Description
   * - ``enable``
     - bit
     - 0
     - Assert to let the filter forward bytes. While low every byte is dropped.
   * - ``clear``
     - bit
     - 0
     - Hold high to hold the forwarded-byte counter at zero.
