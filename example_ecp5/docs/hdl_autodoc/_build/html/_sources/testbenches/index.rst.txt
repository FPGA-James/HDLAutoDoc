VUnit
-----

tb_stream_filter
~~~~~~~~~~~~~~~~

:File: ``tb/vunit/tb_stream_filter.sv``
:Tests module: :doc:`/modules/stream_filter/index`
:Purpose: Testbench for stream_filter. Drives bytes into s_axis and checks which ones come out of m_axis: the filter forwards bytes at or above the threshold and drops the rest.
:Tests: 3 tests

.. list-table::
   :header-rows: 1

   * - Test
     - Purpose

   * - ``passes_at_or_above_threshold``
     - A byte equal to or above the threshold appears on m_axis.

   * - ``drops_below_threshold``
     - A byte below the threshold is dropped.

   * - ``counts_forwarded_bytes``
     - The counter counts only the bytes that were forwarded.
