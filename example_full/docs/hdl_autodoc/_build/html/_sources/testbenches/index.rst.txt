tb_sample_ctrl
~~~~~~~~~~~~~~

:File: ``tb/vunit/tb_sample_ctrl.vhd``
:Tests module: :doc:`/modules/sample_ctrl/index`
:Purpose: Testbench for sample_ctrl. Starts a capture and checks the controller arms, runs for its window, then reports done and waits for the request to be withdrawn.
:Tests: 3 tests

.. list-table::
   :header-rows: 1

   * - Test
     - Purpose

   * - ``capture_window_length``
     - The window opens after arming and lasts RUN_CYCLES cycles.

   * - ``idle_without_start``
     - Nothing runs without a start request.

   * - ``overflow_ends_window``
     - An overflow ends the window early.

tb_stream_filter
~~~~~~~~~~~~~~~~

:File: ``tb/vunit/tb_stream_filter.sv``
:Tests module: :doc:`/modules/stream_filter/index`
:Purpose: Testbench for stream_filter. Sends single-byte and multi-byte packets and checks that a packet is forwarded or dropped as a whole according to its first byte.
:Tests: 3 tests

.. list-table::
   :header-rows: 1

   * - Test
     - Purpose

   * - ``forwards_packet_at_threshold``
     - A packet whose first byte reaches the threshold is forwarded.

   * - ``drops_packet_below_threshold``
     - A packet whose first byte is below the threshold is dropped whole.

   * - ``counts_forwarded_packets``
     - Only forwarded packets are counted.
