ctrl (0x00)
-----------

.. list-table::
   :header-rows: 1
   :widths: 15 20 20 45
   :class: register-table

   * - Field
     - Type
     - Default
     - Description
   * - ``start``
     - bit
     - 0
     - Assert to start a capture. Hold until the status reports done, then clear.
   * - ``filter_enable``
     - bit
     - 0
     - Assert to let the stream filters forward packets. While low every packet is dropped.
   * - ``clear``
     - bit
     - 0
     - Hold high to hold the forwarded-packet counter at zero.

     - bit

     - Default
     - Description
