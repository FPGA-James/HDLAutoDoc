p_adc_capture
=============

Description
-----------

p_adc_capture\: Registers each sample and flags FIFO overflow.

Source
------

.. code-block:: systemverilog

       always_ff @(posedge adc_clk) begin : p_adc_capture
           if (adc_rst) begin
               wr_en    <= 1'b0;
               wr_data  <= '0;
               overflow <= 1'b0;
           end else begin
               wr_en   <= en_sync;
               wr_data <= adc_data;
               if (wr_en && fifo_full) begin
                   overflow <= 1'b1;
               end else if (!STICKY_OVERFLOW) begin
                   overflow <= 1'b0;
               end
           end
       end
