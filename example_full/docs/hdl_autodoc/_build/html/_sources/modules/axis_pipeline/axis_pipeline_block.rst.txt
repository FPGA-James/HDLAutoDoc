Interfaces
----------

``axis_if`` — instantiated here as ``s_if``, ``m_if``.

.. list-table::
   :header-rows: 1

   * - Signal
     - Type
     - master
     - slave
     - Description

   * - ``tdata``
     - ``logic[7:0]``
     - out
     - in
     - Payload byte.

   * - ``tvalid``
     - ``logic``
     - out
     - in
     - Master has a byte; slave takes it when tready is also high.

   * - ``tready``
     - ``logic``
     - in
     - out
     - Slave can take a byte this cycle.

   * - ``tlast``
     - ``logic``
     - out
     - in
     - Last byte of a packet.
