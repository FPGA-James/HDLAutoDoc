p_next_state¶

Source file: sample_ctrl.vhd
Source line: 115
Block type: process
Sensitivity list: state, start, overflow, run_last

Description¶

p_next_state: Combinational next-state logic. A start request arms the controller; the window ends after RUN_CYCLES cycles or on overflow; DONE is left when the request is withdrawn.

Source¶

p_next_state : process(state, start, overflow, run_last) is
begin
    next_state <= state;

    case state is
        when IDLE =>
            if start = '1' then
                next_state <= ARMED;
            end if;

        when ARMED =>
            next_state <= RUN;

        when RUN =>
            if run_last = '1' then
                next_state <= DONE;
            elsif overflow = '1' then
                next_state <= DONE;
            end if;

        when DONE =>
            if start = '0' then
                next_state <= IDLE;
            end if;
    end case;
end process p_next_state;
